# オセロ対局アシスタント

ブラウザだけで動く、2人対局用のオセロ盤＋着手アシスタント。単一 HTML ファイル（依存ライブラリなし・オフライン動作）。

## 公開ページ

https://take6fan.github.io/othello/

## iPhone での使い方

1. Safari で上記 URL を開く
2. 共有ボタン → **ホーム画面に追加**
3. ホーム画面のアイコンから起動（アドレスバーなしの全画面で動作）

音（効果音・BGM）は iOS の仕様上、画面を一度タップしてから鳴りはじめます。

## 機能

- **ふたりで対局**：8×8 の盤を2人で共有して打つ（CPU は着手しない）
- **EGO-GPT と対戦**：1人でコンピュータと対局。先手（黒）／後手（白）を選べる
- 着手アシスト：ネガマックス＋α-β 探索（反復深化・時間切れ打ち切りつき／終盤11マス以下は完全読み）
- アシスト対象の切替：両方／黒だけ／白だけ／アシストなし／アシスト・印なし
- 候補手 上位3件（相手の応手数・裏返り枚数・評価値）
- 棋譜、1手戻す（EGO-GPT 戦では相手の応手ごと戻る）、最初から
- Web Audio API による効果音・BGM（音源ファイルなし、すべて合成）

## EGO-GPT の強さ

| レベル | 中身 | 目安 |
|---|---|---|
| 初級 | **手加減する**。隅を人間に残し、X打ち・C打ちを好み、リードするほど緩い手を選ぶ。負けているときだけ持ち直して一方的にしない | ランダム着手の相手にも16勝4敗で**負ける**（実測20局） |
| 中級 | 3手読み。4回に1回は最善を外す。終盤8マスは完全読み | 2手読み相手に12勝12敗の互角（実測24局） |
| 上級 | 時間の許す深さまで（最大7手）＋終盤12マス完全読み。手加減なし | 中級に12戦全勝（実測） |

思考は端末の速さに応じて自動で深さを調整し、時間切れで打ち切るため、iPhone でも固まりません。
