# オセロ対局アシスタント

ブラウザだけで動く、2人対局用のオセロ盤＋着手アシスタント。単一 HTML ファイル（依存ライブラリなし・オフライン動作）。

## 公開ページ

https://take6fan.github.io/othello/

## iPhone での使い方

1. Safari で上記 URL を開く
2. 共有ボタン → **ホーム画面に追加**
3. ホーム画面のアイコンから起動（アドレスバーなしの全画面で動作）

音（効果音・BGM）は iOS の仕様上、画面を一度タップしてから鳴りはじめます。

## 3つのモード

| モード | 内容 |
|---|---|
| **アシストモード**（既定） | 実際の盤で打つときの相談役。次の一手・その理由・候補手・打てる場所の印（・）と最善手の印（〇）を出す |
| **ふたりで対局** | ふたりで交互に打つ。アシストも印も一切出さない |
| **EGO-GPT と対戦** | ひとりでコンピュータと対局。強さ3段階、先手（黒）／後手（白）を選べる。アシストも印も出さない |

②③ を選ぶとアシストの選択はすべて外れ、対局に必要な項目だけが残ります。
対局は［対局スタート］で開始、［リスタート］でやり直し。モード・強さ・石の色を変えると開始前に戻ります。
**スタートを押すまで盤に石は置かれません**（空の盤を表示）。

## 機能

- 着手アシスト：ネガマックス＋α-β 探索（7手読み／終盤12マス以下は完全読み）
- 候補手 上位3件（相手の応手数・裏返り枚数・評価値）
- 棋譜、1手戻す（EGO-GPT 戦では相手の応手ごと戻る）
- 印を出さないモードでは空きマスすべてを押せる。置けない場所を押すと理由を表示する
- 市販の盤と同じ内枠（中央16マスの囲みと四隅の打点）
- Web Audio API による効果音・BGM（音源ファイルなし、すべて合成）

## EGO-GPT の強さ

| レベル | 中身 | 実測 |
|---|---|---|
| 初級 | **強く手加減する**。隅は取らずに人間へ残し、X打ち・C打ちを好み、目先の枚数に飛びつく。ほぼ常時手を抜く | ランダム着手の相手にも3勝27敗（−20.9石）、1手読み・2手読み相手には0勝20敗で**負ける** |
| 中級 | 3手読み。4回に1回は最善を外す。終盤8マスは完全読み | 2手読み相手に9勝11敗の互角 |
| 上級 | 7手読み＋終盤13マス完全読み。手加減なし | 中級に8戦全勝（平均+41石） |

## 探索エンジン

読む深さは**端末によらず一定**（時間切れによる打ち切りはしない）。そのために探索そのものを速くしている。

- 盤は `Int8Array`。1手ごとに盤を複製せず、返した石を記録して戻す（make / unmake）
- 8方向の並びを表にしておき、探索中は配列を一切生成しない
- 置換表（Zobrist ハッシュ、26万エントリ）で同一局面の読み直しを省く
- PVS（最善手だけ広く読み、残りは狭い窓で確認）

素朴な実装比で中盤6手読みが約6倍速。上級の1手あたり最長思考時間は開発機で約0.5秒。
