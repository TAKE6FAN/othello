# オセロ対局アシスタント

ブラウザだけで動く、2人対局用のオセロ盤＋着手アシスタント。単一 HTML ファイル（依存ライブラリなし・オフライン動作）。

## 公開ページ

https://take6fan.github.io/othello/

## iPhone での使い方

1. Safari で上記 URL を開く
2. 共有ボタン → **ホーム画面に追加**
3. ホーム画面のアイコンから起動（アドレスバーなしの全画面で動作）

音（効果音・BGM）は iOS の仕様上、画面を一度タップしてから鳴りはじめます。

## 機能

- 8×8 の対局盤（2人対局。CPU が自動で着手することはない）
- 着手アシスト：ネガマックス＋α-β 探索（中盤6手読み／残り11マス以下は完全読み）
- アシスト対象の切替：両方／黒だけ／白だけ／アシストなし／アシスト・印なし
- 候補手 上位3件（相手の応手数・裏返り枚数・評価値）
- 棋譜、1手戻す、最初から
- Web Audio API による効果音・BGM（音源ファイルなし、すべて合成）
